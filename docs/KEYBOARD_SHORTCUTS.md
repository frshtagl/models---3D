# Keyboard shortcuts

The workstation supports keyboard-first navigation while the pointer is over the page or 3D viewport.

## Development stages

| Keys | Action |
|---|---|
| `←` / `→` | Previous / next Carnegie stage |
| `Home` / `End` | First / last stage |
| `Space` | Play / pause the stage sequence |

Manual stage navigation pauses automatic playback.

## Camera and anatomy

| Keys | Action |
|---|---|
| `1` | Anterior view |
| `2` | Posterior view |
| `3` | Right view |
| `4` | Left view |
| `5` | Superior view |
| `6` | Inferior view |
| `+` / `-` | Zoom in / out |
| `0` or `R` | Reset camera orientation and zoom |
| `A` | Show all anatomy layers |
| `I` | Isolate the selected structure |

Zoom changes preserve the current orbit direction. Selecting a numbered camera view changes orientation while retaining the current zoom level.

## Workspace

| Key | Action |
|---|---|
| `G` | Toggle the teaching guide |
| `F` | Toggle full-screen mode |
| `?` | Open / close this shortcut reference |
| `Esc` | Close the shortcut reference, or close the teaching guide |

## Input safety

Shortcuts are ignored while typing in an input, text area, or editable field, or while changing a select control. Space and Enter retain their normal activation behaviour when a button is focused. Browser and operating-system combinations using Ctrl, Command, or Alt are left untouched.
