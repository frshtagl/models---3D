# Umbilical and Cardinal Veins — Browser Teaching Guide

## Launch

~~~bash
npm install
npm run dev
~~~

Open the local Vite URL, usually http://localhost:5173.

## Open the guided sequence

1. Select **Teaching guide** in the top bar.
2. Use **Next lesson** / **Previous** to move through the 22 lessons.
3. Steps 1–14 cover vitelline, portal and hepatic outflow development.
4. Steps 15–16 cover the paired umbilical veins.
5. Steps 17–22 cover the cardinal system and the two IVC interpretations.
6. The 3D scene remains orbitable and selectable while the teaching card is open.

## New umbilical lessons

### Early paired umbilical veins

- Set CS10.
- Show placenta, umbilical cord, left umbilical inflow, right umbilical vein and early sinus-horn connections.
- Trace placental return toward the venous pole.
- Point out that the left umbilical inflow is reused from the portal context layer; it is not duplicated.

### Right umbilical-vein regression

- Set CS14.
- Select right-umbilical-vein.
- Compare its regressing state with the persistent left-umbilical-inflow.
- Keep human-portal-sinus and human-ductus-venosus visible to distinguish the two left-to-right shunts.

## New cardinal lessons

### Anterior and common cardinal veins

- Set CS12.
- Select common-cardinal-veins.
- Trace anterior cardinal return into the common cardinal veins and then to the sinus venosus horns.
- The cranial ends are schematic anchors; the head and neck are not modeled.

### Caudal cardinal extension

- Set CS15.
- Select caudal-cardinal-veins.
- Follow both channels from the common cardinal region toward the pelvis.
- Turn on the dorsal aorta and paired mesonephroi for positional orientation.

### Subcardinal plexus and longitudinal channels

- Set CS15 for the plexus, then CS16 for longitudinal subcardinal channels and the intersubcardinal connection.
- Select subcardinal-mesonephric-plexus or intersubcardinal-anastomosis.
- Explain that the current connection is not the completed adult renal collar.

### Compare IVC interpretations

Use the **Cardinal / IVC interpretation** selector in the left control panel.

- **Conventional segmental model:** displays the paired supracardinal channels and the familiar four-segment IVC teaching explanation.
- **Human reconstruction · 2015:** hides the independent supracardinal layer and emphasizes caudal cardinal and subcardinal continuity.

Do not teach both as one combined vessel system.

## Scientific caveats

- The current stage timeline ends at CS16; the mature IVC and azygos configuration is not complete.
- The human 2015 reconstruction continues through CS18–CS23.
- The head / neck territories of anterior cardinal veins are not modeled.
- The mesonephroi and dorsal aorta are positional context meshes.
- The subcardinal plexus is simplified to editable centre-lines.
- All geometry is schematic and not to scale.
- The conventional supracardinal model and the 2015 human caudal-cardinal model are alternative interpretations.
